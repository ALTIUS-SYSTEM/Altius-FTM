**Altius Field Task Manager (FTM)** mengoordinasikan pekerjaan armada dan transportasi melalui tiga permukaan:

| Permukaan | Pengguna | Peran |
|---|---|---|
| **Dasbor web** | Dispatcher, supervisor, admin | Membuat tugas, memantau rute, meninjau laporan |
| **Aplikasi lapangan** | Pengemudi | Menerima pekerjaan, tetap bekerja offline, sinkron saat online |
| **HTTP API** (`/api/v3`) | Integrator & klien pihak pertama | Akses JSON terautentikasi ke tugas, sync, roster, dan lainnya |

## Tujuan produk

- Menugaskan dan mengurutkan tugas lapangan dengan konteks hub / gudang yang jelas.
- Melacak kemajuan dengan sinyal GPS dan geofence tanpa menyematkan rahasia peta di aplikasi klien.
- Menjaga perangkat pengemudi tetap berguna offline; merekonsiliasi dengan server memakai tanda terima peristiwa yang andal.
- Mengisolasi data penyewa berdasarkan keanggotaan organisasi dan hub dari token identitas.

## Untuk siapa portal ini

Situs ini untuk **IT pelanggan** dan **integrator**: pengetahuan produk, ekspektasi identitas, dan penggunaan API. Bukan buku panduan rekayasa internal.
